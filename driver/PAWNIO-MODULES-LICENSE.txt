These are compiled PawnIO modules, taken from the official PawnIO.Modules
release (https://github.com/namazso/PawnIO.Modules) as vendored by
LibreHardwareMonitor 0.9.5 (LibreHardwareMonitorLib/Resources/PawnIo/).

Corresponding source: https://github.com/namazso/PawnIO.Modules

The PawnIO kernel driver itself is NOT redistributed with fan-tune. Install it
from https://pawnio.eu (LibreHardwareMonitor and FanControl install it the same
way). fan-tune only loads these modules into the already-installed driver.

Why they are here: with WinRing0 being flagged by Defender and blocked when
HVCI / Smart App Control enforce the vulnerable-driver list, PawnIO is the
signed path that keeps working. Both files must sit next to fan-tune.exe.
