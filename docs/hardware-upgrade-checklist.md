# 散热改造清单（软硬结合，按执行顺序）

> 背景：显卡（3070 AORUS MASTER，240W）、内存（Corsair LPX 3600 现跑 2133）、NVMe（3 块，主盘致态 TiPlus7100）三个热点同源——3070 的热 + 紧凑机箱换气率低。
> 风扇曲线已从"跟硬盘温度"纠正为：**冷排/顶部 → 建议跟 `gpu:0`；机箱扇 → 建议用 Budget 模式**。

## ① 3070 降压（当天可做，收益最大）

两种方式，任选或叠加：

**A. 功耗墙快试**（零安装，管理员 PowerShell）：
```powershell
nvidia-smi -pl 180        # 240W → 180W
nvidia-smi -q -d POWER    # 确认已生效
```
跑 20 分钟游戏对比温度/帧数；重启后失效（需重设）。

**B. Afterburner 曲线降压**（推荐长期方案）：
1. 打开 MSI Afterburner → 按 `Ctrl+F` 打开电压/频率曲线；
2. 找到 0.900V 点，把它的频率锁到 **1845MHz**，然后把该点右侧的整条曲线**拉平**（全段同频）；
3. 应用后跑游戏验证稳定性（如不稳，降到 1800MHz 或 0.9125V）；
4. 预期：核心降 **10~15°C**，功耗 240W → **150~170W**，性能损失 1~3%。

> 这一步同时缓解内存和 NVMe 的温度（少烤了 1/3 的热量）。

## ② 内存风扇（3D 打印 + 采购）

**模型**：MakerWorld 的 [Ram Cooler (Dual 60mm Fans)](https://makerworld.com/en/models/1834180-ram-cooler-dual-60mm-fans)（5.0 分/13 条评价，评论区实测有效）
- 支持单/双 60mm 扇，2×50mm 铜柱架在主板螺柱上，100% 填充打印；
- **打印材料用 PETG**（机箱内 40°C+，PLA 会蠕变）；
- 需要：50mm 铜柱 ×2、M3 螺丝若干（看模型 BOM）。

**风扇**：60mm **12V 4pin PWM** ×1~2（别买 5V USB 款，fan-tune 管不到）
- 可选：Noctua NF-A6x25 PWM / 利民 TL-6015（60mm PWM 可选面窄，先打印量空间再买）。

**接线**：接空着的 SYS_FAN 头（Fan#2/3/4/#6）→ fantune.json 启用该通道 → 曲线跟 `nvme:0` 或机箱温度。

## ③ 4090 拆机扇（12 元/把，试水玩法）

**买之前认准**：
- 优先"**已改好 4pin**"或**非公版拆机扇**（标准 4pin，直接插主板）；公版是排线，要自己改线；
- 确认支持 **PWM 调速**（全速 12V 版本当进气扇 = 噪音灾难）；
- 多买 1-2 把备用（拆机件轴承状态抽奖）。

**用法**（10mm 薄是核心优势）：
1. **前面板**：TL-S12R **只接 ARGB 灯线（PWM 拔掉，当灯牌）** + 4090 扇装内侧实际吹风 → 颜值和风量兼得；
2. **底部**（有位的话）：朝上吹显卡进风区；
3. 打印 **115→120mm 转接框**（异形孔距 38×28mm）。

**注意**：串联（同位置叠加）不划算——风量被弱扇卡住 + 拍频噪音；要"增压"就并联（多开位置）。

## ④ M.2 导热垫（20 元内）

1. 拆下 M2_1 马甲，量原装导热垫厚度；
2. 换 **1.5~2mm 高导热软垫**（莱尔德 90000 系列或国产 12W/mK 以上）；
3. 目标：让马甲真正吃到热（原装垫经常差一点没压实）。

## ⑤ 开 XMP（免费性能）

- BIOS → XMP/DOCP → 从 **3200** 起试（64GB 双 rank 不一定能上 3600）；
- 开完跑一次内存稳定性测试（TM5 或 MemTest）；
- 开了之后内存更热（1.35V）→ 配合 ② 的内存风扇一起。

## ⑥ 换机箱（大改造，最后做）

**硬指标**：顶部支持 **280 冷排** + MATX + 显卡限长 ≥ 320mm + 白色/侧透优先。

| 候选 | 价格 | 亮点 |
|---|---|---|
| **华硕 AP201 冰立方（白色网孔版）** | ¥350-400 | 顶部明确支持 280 冷排；全网孔；MATX 散热标杆 ← **首推** |
| 追风者 XT M3 小旋风（白色） | ¥299 | MATX 侧透、360 水冷位（280 兼容性下单前确认） |
| 骨伽 小乘风 MX600 mini | ¥299 | 自带双 16cm ARGB 大风扇，网孔侧板 |
| 联力 Lancool 207（ATX 大一圈） | ¥400 左右 | 前部双 14cm 大风扇直吹显卡 |

**下单前核对**：280 冷排位、显卡限长（量 AORUS 3070 实际长度，约 30cm）、电源尺寸（ATX/SFX）。

## 执行顺序建议

```
今天：① 降压（A 或 B） → 跑一轮峰值温度基线
本周：② 内存风扇（打印 + 到货 + 接 fan-tune 通道）
试水：③ 4090 扇（12 元，买回来测完再装）
顺手：④ M.2 导热垫 + ⑤ XMP
下一波：⑥ 换机箱（大改造，等前面几项的效果数据出来再决定值不值）
```

**每做一项，跑 20 分钟游戏记录温度对比**（CPU / GPU 核心 / 三块盘），一次只改一个变量。
